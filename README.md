# TripSplit

TripSplit is a native Android app for splitting expenses on shared trips. Create a trip, invite friends, add expenses, see who owes whom and settle up with the minimum number of payments.

## Features

| | Feature | Status |
|---|---|---|
| ✅ | Create, edit and delete trips | done |
| ✅ | Participants: add, rename, remove, invite with a code, join a trip | done |
| ✅ | Expenses: add, edit, delete, category, payer, equal split, history with filters | done |
| ✅ | Balances per participant and a settlement plan with the minimum number of payments | done |
| ✅ | Record payments and mark plan items as paid | done |
| ✅ | Trip summary: total, per person, spending by category and by day | done |
| ✅ | Light and dark theme, Inter font, one design system | done |
| 🚧 | Local persistence (Room) — data lives in memory for now | planned |
| 🚧 | Multi-currency conversion into the trip base currency | planned |

## Design system

Everything visual comes from `core/designsystem`, screens never use literal colors, sizes or fonts.

- **Colors** — semantic tokens in `AppColors` (`canvas`, `surface`, `text`, `textMuted`, `accent`, `accentSoft`, `border`, `danger`, ...) with a light and a dark palette: `AppTheme.colors.*`.
- **Typography** — Inter, 19 roles from the designer's sheet (`complete_design/SplitTrip_typography.png`) mapped to `MaterialTheme.typography.*`.
- **Spacing** — scale 4 / 8 / 12 / 16 / 24 / 32 dp (`Spacing.space4` ... `space32`), plus `Sizes`, `Strokes`, `Elevations`.
- **Components** — small reusable composables in `core/designsystem/components`; every screen and every component has a `@Preview` in light and dark.
- **Touch targets** — at least 48 dp.

## Architecture

Feature-based clean architecture, Jetpack Compose UI, manual dependency injection.

```text
app/src/main/java/com/abzal/tripsplit/
├── TripSplitApp.kt            Application, holds the AppContainer
├── MainActivity.kt            sets the theme and the NavHost
├── core/
│   ├── designsystem/          colors, typography, dimens, theme, components/
│   ├── di/                    AppContainer, injectedViewModel
│   ├── navigation/            Routes, AppNavHost, graphs/ (one per feature)
│   ├── preview/               AppPreview, ThemePreviews, sample data
│   └── util/                  formatters
└── features/
    ├── autharization/         sign in, sign up, password reset, profile
    ├── home/                  trips list
    ├── trips/                 create, edit, delete trip
    ├── expenses/              overview, history, details, add/edit, currency picker
    ├── participants/          participants, invitations, join a trip
    ├── balances/              balances, settle up, record payment
    └── insights/              spending insights
        ├── domain/            models and repository interfaces
        ├── data/              repository implementations
        └── presentation/      Screen, Route, ViewModel, components/
```

## Tech stack

Kotlin · Jetpack Compose · Material 3 · Navigation Compose · ViewModel + StateFlow · min SDK 24

## Build and run

Requirements: Android Studio, JDK 11+, Android SDK, an emulator or a device.

1. Open the project in Android Studio and wait for the Gradle sync.
2. Select the `app` configuration and press **Run**.

From the command line:

```bash
./gradlew :app:assembleDebug
```
